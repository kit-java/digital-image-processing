# digital-image-processing
A Jupyter Notebook script containing digital image processing techniques using OpenCV,scikit-image,and NumPy.

## Prerequisites
The notebook requires the following Python libraries:
`pip install numpy scipy opencv-python scikit-image matplotlib`

## Usage
1.Clone the repository.
2.Place the required source images (`pepper.jpg`, `dark_road_1.jpg`, `dark_road_2.jpg`, `dark_road_3.jpg`, `clock.jpg`) in the same directory as the Jupyter Notebook.
3.Open the `.ipynb` file and execute the cells to visualize the image processing steps and outputs.
